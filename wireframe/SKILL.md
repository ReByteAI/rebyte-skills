# wireframe

Produce low-fidelity wireframes to compare layouts and flows.

## Default form
- Greyscale, no real images (use neutral boxes)
- System font; consistent stroke weight
- 3–6 variants for a single screen, OR a 3–8 step storyboard

## When variants
Label each `Option A / B / C` with a one-sentence rationale ("A leans on the hero, B leans on social proof").

## When storyboard
Number screens; show the user goal at the top of each.

## When not to use
Use `interactive-prototype` once the layout is locked. Use `make-a-deck` for narrative pitches.
