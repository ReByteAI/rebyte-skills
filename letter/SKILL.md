# letter

Produce a formal letter with a clear purpose and ask.

## Variants
- **Cover** (default): introduce yourself + match to role
- **Resignation**: state intent + last day + gratitude
- **Recommendation**: who, capacity, traits with examples, endorsement
- **Outreach**: cold ask with specific reason for this person
- **Memo**: internal communication with subject line

## Structure
1. **Sender block** — name + contact (top right or top)
2. **Date**
3. **Recipient block** — name + title + org + address
4. **Salutation** — "Dear <Name>," with real name when known
5. **Opening** — purpose in the first sentence
6. **Body** — 1–3 short paragraphs of evidence/context
7. **Close** — explicit ask + sign-off + signature

## Length budget
- Cover/outreach/recommendation: ≤ 1 page
- Resignation/memo: ≤ ½ page

## Form-specific verification
- Recipient name correct (ask if unknown — never "To Whom It May Concern" if avoidable)
- Purpose clear in the first sentence
- Specific ask, not vague "would love to chat"
- Signature line + printed name
